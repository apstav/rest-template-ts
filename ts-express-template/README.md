# rest-api-node-typescript

RESTful API with node, express, typescript and jest!

## API with following requirements in mind:
1. Handle CRUD (create, read, update, delete) on resources 
2. Data will be returned in JSON format
3. All requests will be logged to the console

It is a great starting point for learning rest APIs.

## Technologies used:
- Typescript
- Express.js
- jest
- axios
- cors
- mongoose
- winston
- swagger

## Setup
1. Install dependencies
```
npm install or yarn
```
2. Build your api
```
npm run build or yarn build
```
3. Start your api
```
npm run start or yarn start
```

## Development
```
npm run test or yarn test

//watch mode
npm run test:watch or yarn test:watch
```
